# Начало работы

**Status:** skeleton · **Owner:** product/documentation owner

Система находится перед PHASE 1A и пока не создаёт торговые сигналы. Команды PHASE 0 проверяют configuration, environment и внешний data root. Любой будущий пользовательский вывод использует `ru-RU` с fallback `en-US`; технические идентификаторы остаются английскими.
